# 第5回 宿題（実装）作業記録

answer.md には理解に必要な手順と結果だけを書く。この記録には、試したこと・結果・判断を時系列で残す。

## 目的

検索結果に用語索引の手がかりを添え、モデルが自分で索引を引いて別のページを開けるようにする。複数ページにまたがる根拠（第3回 p.13・39・40）に届くかを確かめる。

## 手順

| # | やること | コマンド・ファイル | LLM | 再現性 |
|---|---|---|---|---|
| 1 | 各ページから専門用語を抜き出す（10ページずつ、間隔20秒、503は再試行） | `uv run --env-file .env python -m scripts.build_term_index` → `data/rag_data/term_index.json` | 使う（約22回） | ぶれる。途中から再開できる |
| 2 | 表記をプログラムでそろえる（NFKC・大文字小文字・記号・語末の長音） | `app/term_index.py` の `normalize()` | 使わない | 決まる |
| 3 | 表記揺れ（同じ概念・ものを指す別表記）を探させる | `uv run --env-file .env python -m scripts.group_terms` → `data/rag_data/term_groups.json` | 使う（1回） | 大きくぶれる |
| 4 | 表記揺れを人が確かめる | `term_pairs.csv` | — | 人の判断 |
| 5 | 引く：完全一致 → 部分一致 → 2文字の組の重なりで上位5件 | `lookup_term` | 使わない | 決まる |
| 6 | 添える：検索結果の各ページに、2〜4ページに出る用語とそのページIDを添える | `--index` の `search_materials` | 使わない | 決まる |
| 7 | 比べる：2つの質問を `--index --trace` と通常の検索で実行する | `uv run --env-file .env python -m app.agent --index --trace "..."` | 使う | ぶれる |

実験の生の出力と補助スクリプトは `runs/`（git の対象外）に置く。`runs/groups/` が表記揺れの各実行、`runs/exercise/` が演習の実行ログ、`runs/tools/` が比較実験と組の集計・下書きラベルのスクリプト。

## 記録

### 既存の用語（graph.json）を使わなかった理由

- 72語しかなく、「コンパクション」「セッション」がない。
- 第3回 p.13・39・40 に共通する用語は `term:memory` だけで、第1〜3回の17ページに出てくる。手がかりにならない。

### 手順1：用語の抜き出し

- 214ページすべてで取得できた。795表記、正規化後783語。
- p.39 で「コンパクション」「セッション」、p.40 で「長期メモリ」「日々のメモ」を拾えた。
- p.39 と p.40 には共通の用語がない。添える手がかりだけでは p.39 から p.40 に届かない。

### 手順3：表記揺れのプロンプト

| 版 | 変更 | 残ったグループ数 |
|---|---|---|
| v1 | 「グループにまとめて」、言い換えも可 | 48（半分以上が別概念） |
| v2 | 表記揺れに限定、定義をスキーマの enum と description へ、否定例、「迷ったら、まとめない」「少なくてもかまわない」 | 3、5 |
| v3 | v2 から「少なくてもかまわない」を外す | 6、3 |
| neg | v3 から「迷ったら」を外す | 8、13、8 |
| plain | neg から否定例も外す | 10、14、14 |

- temperature 0 でも、同じ条件で件数が大きく変わる。
- 一覧にない組（AI｜人工知能、PoC｜概念実証など）を返すことがある。一覧を照合せず、知識から答えている疑いがある。
- plain の2回目で、表記が5個を超えるグループが出た（モデル｜AI model/AI モデル/LLMモデル/ML モデル/ベースモデル）。
