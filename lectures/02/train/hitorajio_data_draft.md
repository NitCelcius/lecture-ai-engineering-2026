# 実装(第2回): ひとらじ FAQ データ案

架空のサービス「ひとらじ」(ひとりラジオ向けの録音と振り返りソフト)の FAQ。プランの金額や制限はすべて架空。

## FAQ 5 項目

| key | FAQ の文 | must_include |
|---|---|---|
| length | 1 回の録音は無料プランで 30 分、有料プランで 3 時間までです。 | 30 分, 3 時間 |
| marker | 手を叩くか画面のボタンを押すと、その位置にカットのマークが付きます。 | 手を叩, ボタン |
| rewind | マークを付けたら、文字起こしから戻りたい位置を選ぶと、そこから録音をやり直せます。 | 文字起こし, やり直 |
| export | 書き出せる形式は WAV、MP3、字幕ファイル SRT の 3 つです。 | WAV, MP3, SRT |
| support | サポートの受付は平日 10:00〜17:00 で、返信は 2 営業日以内です。 | 平日, 10:00 |

## 根拠ありの質問(各 key 4 テンプレート + test 専用 2 問)

先頭 2 つを train、3 つ目を valid、4 つ目を test(ノートブックと同じ分け方)。

- length: 1 回でどのくらい録音できますか / 無料プランの録音時間の上限は？ / 長時間の収録はできますか / 録音できる最大の長さを教えてください ; test 専用: 有料プランにすると何時間まで録れますか / 30 分を超える録音はできますか
- marker: 噛んだところにマークを付けるにはどうしますか / カットしたい位置はどうやって示しますか / マークの付け方を教えてください / 手を叩く以外の方法はありますか ; test 専用: ボタンを押すとどうなりますか / 録音中に失敗した位置を記録できますか
- rewind: 言い直したいときはどうしますか / 喋ったところに戻るには？ / 途中からやり直せますか / 戻る位置はどうやって決めますか ; test 専用: 文字起こしを見て戻る場所を選べますか / 噛んだ後に録音を巻き戻せますか
- export: どんな形式で書き出せますか / 音声ファイルの形式を教えてください / 字幕は出力できますか / MP3 で保存できますか ; test 専用: WAV で書き出せますか / 書き出せるファイルの種類は何ですか
- support: サポートはいつ受け付けていますか / 問い合わせの対応時間は？ / 返信までどのくらいかかりますか / 質問したら何日で返事が来ますか ; test 専用: 問い合わせの受付時間帯を教えてください / サポートの返信は当日中ですか

## 根拠なしの質問(12 問)

ノートブックと同じく 4 問ごとに train 2 / valid 1 / test 1 に振り、さらに test 専用 4 問を足す。
「近いけれど FAQ に無い」質問(近傍)と、無関係な質問を混ぜる。基礎の実験で残った失敗は、話題の近い根拠なし質問に別項目の答えを当てる型だったため、近傍を多めにしている。

| 区分 | 質問 | 近い key |
|---|---|---|
| train | オフラインでも録音できますか | (無関係) |
| train | 無料プランの録音は月に何回までですか | length |
| valid | カットは自動で行われますか | marker |
| test | 複数人で同時に録音できますか | (無関係) |
| train | MP4 の動画として書き出せますか | export |
| train | 料金はいくらですか | length |
| valid | サポートは土日も対応していますか | support |
| test | 文字起こしは英語にも対応していますか | rewind |
| test 専用 | 録音データは何日間保存されますか | (無関係) |
| test 専用 | 電話でサポートを受けられますか | support |
| test 専用 | 付けたマークは後から動かせますか | marker |
| test 専用 | 文字起こしの精度はどのくらいですか | rewind |

正解は「この FAQ には記載がありません。運営に確認が必要です。」、`needs_review: true`、must_include は「確認」。

## 件数(ノートブックと同じ構成)

train 14(根拠あり 10 + なし 4)、valid 7(5 + 2)、test 21(根拠あり 15 + なし 6)。

## 後で決めること

- 根拠なしの学習例を増やす条件(例: train の根拠なしを 4 → 8 にする)を比較に加えるか。基礎で立てた「データ側の問題」という仮説の検証になる
- 知識を問う質問(セクション 6)は、FAQ にも学習データにも無い 3 問 + 対照 1 問を作り直す(例: 「ひとらじの運営会社はどこですか」「iPhone で使えますか」「次回のアップデートはいつですか」+ 対照「録音は最大何分ですか」)
