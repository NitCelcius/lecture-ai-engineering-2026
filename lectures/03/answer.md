# 第3回 解答

## 演習

- 第1回(素のLLM)とエージェントの回答の違い
  - 同じ質問「AIE2026の講座の宿題にある「3レベル」とは何ですか？」を用いた。第1回のLLMは講座の資料について情報が無いため推測で出力していたが、今回のエージェントは先に講座の用語集を検索し、講座どおりの具体的な内容を出力した。
- `--trace` で見えたツール呼び出し(ツール名と引数)
  - エージェントが利用するツールを文脈に合わせて使い分けていた。
    - 「3レベル」の質問では、「3レベル」を検索するために、用語集を検索するツール `search_glossary` を使用した。
    - 「LoRAとQLoRAの違いは？」の質問では、同じ `search_glossary` を、検索語「LoRA」と「QLoRA」で1回ずつ、合わせて2回使った。
    - 「第2回の内容から確認問題を1問出して」の質問では、`make_quiz` を、引数「第2回」で1回使った。
- 1つの質問での LLM 呼び出し回数(`requests`)：3つの質問全てで2回だった。
- 追加したツールと、docstring に書いた説明
  - `make_quiz` を作成した。これは、指定した回の用語を用語集から1つランダムに抽出し「○○の意味は？」という問題と答えを返すツールである。モデルへの説明(docstring)には、次の記載を含めた。

```
利用者が確認問題・クイズ・小テストを求めたときに使う。出題するときは答えを伏せて問題だけを見せ、利用者が答えたあとで答え合わせをする。
```

  - LLMに「確認問題を1問出して」と頼むと `make_quiz` が使用され、エージェントは問題を出力した。
  - 用語のない回(第0回など)を指定されたときは、エラーにせず「用語集にありません」と返すようにした。

## 宿題

- 取り組んだレベル：発展(a) ADK で作り直す
- やったこと：
    - 演習で作った学習支援エージェントから、指示やツール(3件)は変更せず、エージェントの作成部分を Google のADKを用いて実装した。
      - LLMは `gemini-3.5-flash-lite` を使用した。
    - ADK の標準の実行方法(`adk run`)は回答しか表示しないので、どのツールを使ったか、AI に何回問い合わせたかは別途計測した。
      - リポジトリの直下で `PYTHONPATH=. uv run --with google-adk adk run adk_agent/glossary_agent` を実行するとツールの使用状況やターン数が出力される。
- 結果：
    - 演習と同じ3つの質問を行った結果、動作は演習で実装したものからあまり変化しなかった。3つの質問とも、ADK 版は演習版と同じツールを同じ引数で使い、AI への問い合わせ回数も同じ 2 回だった。
    - 回答は、どちらも用語集の内容に沿っていて、最後に関係する回を示した。文面は実行ごとに多少変化した。たとえば確認問題は用語がランダムに選ばれるので、演習版は「過学習」、ADK 版は「PEFT」が出た。
    - AI に送る文章の量(入力トークン数)は、ADK 版の方がどの質問でも124〜135 tokenほど多かった。

    | 質問 | 演習版(Pydantic AI) | ADK 版 | 差 |
    |---|---|---|---|
    | 3レベル | 1055 | 1181 | 126 |
    | LoRAとQLoRAの違い | 1468 | 1592 | 124 |
    | 確認問題 | 988 | 1123 | 135 |

    - 差の理由として、ADK が指示文の最後にプロンプトを追加していることがわかった。内容は「あなたはエージェントで、内部の名前は glossary_agent である」というものである。演習版は指示文をそのまま送っていて、足されていない。台本つきの偽のAIモデルを使い、送られる指示を取り出して確かめた。
```py
@override
async def run_async(
    self, invocation_context: InvocationContext, llm_request: LlmRequest
) -> AsyncGenerator[Event, None]:
  agent = as_llm_agent(invocation_context)
  if getattr(agent, 'mode', None) != AgentMode.SINGLE_TURN:
    si = f'You are an agent. Your internal name is "{agent.name}".'
    if agent.description:
      si += f' The description about you is "{agent.description}".'
    llm_request.append_instructions([si])
```
    - この1行だけでは、差の全部は説明できない可能性が高い。残りの原因は確かめていない。
    - 足されている場所は ADK のプログラム内にあり、公式ドキュメントには記載を見つけられなかった。https://github.com/google/adk-python/blob/v2.14.0/src/google/adk/flows/llm_flows/prompt/_identity.py#L42
- 気づき・疑問：
    - 同じ仕事をするエージェントなら、道具が違っても、動きと回答はほぼ同じだった。違いが出たのは、書きやすさ、動きの見えやすさ、AI に送る文章の量だった。
    - 自分で書いていない指示が、道具によって足されることがある。指示文を見比べるだけでは、AI が実際に読む内容が同じとは限らない。
    - 分からないこと。AI に送る文章の量の差の残りの原因。ADK に用意されている画面での確認方法(`adk web`)は試していないので、画面で動きがどう見えるか。
AI への問い合わせの1回目で使うツールを決め、2回目でツールの結果を見て回答を書く。LoRA と QLoRA の質問は検索が2回あったが、同時に頼んだので、問い合わせの回数は増えなかった。
